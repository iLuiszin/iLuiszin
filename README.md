### About me

I'm a backend-leaning full-stack developer at [Luby](https://www.luby.com.br/). I like owning a feature from the database to the screen: schema and access rules, APIs, and the React UI on top.

**AI is one of my main focuses**, both in how I build software and in what I ship:

- 🤖 **AI-native engineering:** I run teams of coding agents (Claude, Codex) in parallel waves, each in its own git worktree, with automated review, CI gates and browser QA before anything merges
- 🧠 **AI in the product:** LLM features in production, such as an in-app assistant with tool calling, intent routing, token budgets and usage limits, and AI-written invitation drafts
- 🧰 **Agent tooling:** reusable instruction frameworks, skills and orchestration scripts that keep AI-generated work reviewable and safe

Also:

- 🔭 Building **[WeddingPlan](https://weddingplan.com.br)**: guests, RSVP, budget, tasks, invitations and a public event-site builder for weddings and other events
- 🧱 Care about end-to-end type safety, automated tests and error monitoring
